# Task 2: Data Visualization and Storytelling

This project is part of my **Data Analyst Internship – Task 2**.

I used **Power BI** to create a sales dashboard using a 50-row sales dataset.

### Visualizations Created

* Total Sales
* Total Profit
* Total Orders
* Total Quantity
* Sales by Category
* Monthly Sales Trend
* Sales by Region
* Profit by Category
* Sales by Customer Segment
* Top 10 Products

### Tools Used

* Microsoft Excel
* Power BI

### Key Learning

I learned how to create simple and meaningful charts, use filters and slicers, identify business insights, and present sales data through an interactive dashboard.

### Conclusion

The dashboard provides a clear view of sales, profit, customer segments, regions, and product performance, helping understand the overall business performance.
